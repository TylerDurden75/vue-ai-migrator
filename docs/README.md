# Documentation

- **Root** : `README.md`, `USAGE.md`, `API_KEYS.md`, `CHANGELOG.md` — user and project documentation.
  - **USAGE.md** : installation, free vs AI mode, provider (CLI or `VUE_AI_MIGRATOR_AI_PROVIDER`), examples.
  - **API_KEYS.md** : API keys per provider, `VUE_AI_MIGRATOR_AI_PROVIDER` for provider selection.
- **docs/CHEATSHEET.md** : Quick reference for CLI commands and most used options.
- **docs/ARCHITECTURE.md** : Migration workflow and AST+AI diagrams.
- **docs/TRANSFORMATIONS.md** : Complete list of supported Vue 2→3 transformations.
- **docs/MIGRATION_GUIDE.md** : Vue 2.7 support, compat build vs full migration, recommended workflow.
- **docs/TROUBLESHOOTING.md** : FAQ, common errors and solutions.
- **fixtures/vue2-minimal/** : Minimal Vue 2 project for E2E tests (migrate → fix → build).
- **docs/ROADMAP.md** : roadmap and planned evolutions (v0.6, v0.7, etc.).
- **docs/internal/** : internal notes and docs (stabilization, performance, post-migration fixer architecture, benchmarks). Useful for contributors.
