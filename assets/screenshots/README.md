# Screenshots Directory

This directory contains visual representations of CLI commands and outputs.

## Available Screenshots

### CLI Commands

1. **cli-analyze.md** - Analyze command output
   - Basic analysis
   - Classification mode

2. **cli-migrate.md** - Migrate command output
   - Dry-run mode
   - Diff visualization

3. **cli-report.md** - Report command output
   - Console format
   - Markdown export

4. **cli-rollback.md** - Rollback command output
   - Full rollback
   - Single file rollback

## Usage

These markdown files represent what actual screenshots would show. They can be:

- Converted to images using tools like `md-to-png`
- Used as reference for creating actual screenshots
- Included in documentation

## Creating Actual Screenshots

To create actual screenshots:

1. Run the commands in a terminal
2. Use screenshot tools:
   - **macOS**: Cmd+Shift+4
   - **Linux**: `gnome-screenshot` or `scrot`
   - **Windows**: Snipping Tool
3. Save as PNG files in this directory
4. Update README.md to reference the images

## Tools for Screenshots

- **Terminal Screenshots**: `asciinema` for animated terminal recordings
- **Static Screenshots**: Built-in OS tools
- **GIF Creation**: `peek` (Linux), `Kap` (macOS), `LICEcap` (Windows)
