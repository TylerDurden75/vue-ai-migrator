# Assets Directory

This directory contains visual assets for vue-ai-migrator.

## Structure

```
assets/
├── logo.svg              # Main logo (SVG format)
├── logo.png              # Logo PNG (512x512 for npm)
├── favicon.ico           # Favicon for GitHub
├── banner.png            # Banner for README (1200x600px)
├── demo.gif              # Animated demo GIF
├── screenshots/          # CLI screenshots
│   ├── analyze.png
│   ├── migrate.png
│   ├── diff.png
│   └── report.png
├── diagrams/             # Architecture diagrams
│   ├── architecture.svg
│   ├── workflow.svg
│   └── comparison.svg
└── examples/             # Code examples visuals
    ├── before-after.png
    └── transformation.png
```
